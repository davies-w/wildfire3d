## Learning and evaluation proposal
48 training,16 validation,16 untouched test configurations total. Mixed lots split40/12/12 randomly after geometry acceptance, blind to outcomes; single cases split2/1/1 per canopy type. No cells/times/component copies from a held-out configuration used in fitting. All candidate models train on identical configuration IDs and physical targets. Test layouts are drawn from same conditional distribution; no claim this proves generalization to larger lots or new wind/moisture/species. Small pilot learning curves determine whether80 configurations suffice; no assurance of accuracy from count alone.

Compare (1) a shared pair-interaction/local state-transition model and (2) a shared neighbourhood model able to account for simultaneous heating/shielding, with independent additive baseline. These are reusable learned rules conditioned on component type, geometry and state, not one fitted model per layout. Each canopy/building/ground needs spatial state or a spatial decoder to predict heat fields; a single scalar per tree cannot represent requested fidelity. Architecture/parameter count and normalization are to be fixed during training-side development, prior to test use. The proposed neighbourhood model is not yet implemented. No FDS values used during inference.

Targets: time-dependent gas temperature andHRRPUV fields; spatial vegetation temperature/remaining fuel and fuel-release histories; temperatures,incident radiation and convection on ALL four building faces,roof and bare ground. HRRPUV is a flame/reaction-zone proxy. Losses separately normalized and balanced by component and quantity; use active-region and whole-domain scores so cold ground/air cannot dominate. Compare autonomous rollouts and heat dose/peaks/timing alongside instantaneous maps. Use training-only scaling,validation for selection,test once frozen. No ignition classification gate. Total-loss reduction alone is insufficient if one component worsens badly.
