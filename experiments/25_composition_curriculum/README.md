Artificial exposure source relative strength0.35–1.65,duration5–30s,bearing0–360degrees. These are source-control inputs, NOT measured incident heat flux; exact radiant/convective forcing implementation and reference power must be frozen before launch. H symbol is schematic, not literal heater geometry/location. Need expose response under heating,cooling,partial fuel loss and stronger heating; outcomes never forced/balanced on test data. Full building used here to cover walls,roof and thermal response; not a tree+building example. Forcing must include spatially varying/directional exposure, with measured incoming/net flux distinguished. Pure prescribed surface temperature would not teach response and is NOT the intended input.

32 tree–tree:16ordered source/receiver model pairs x two independent gap/bearing draws. One randomly assigned draw per ordered pair guaranteed training; remaining16split8train/4val/4test. Gapuniform0.5–3.5m,bearingcontinuous0–360,wind fixed. Source/receiver order matters under wind. Each tree model occurs training; tiny holdouts need not contain everyordered pair. No buildings.

16 tree–building: four independent placements per tree model,2/1/1split. Varied side and separation0.5–3.5m relative to the same square building; includes upwind/downwind situations by random placement.

16 small groups:8three-tree(no building),8two-tree+building. Eachfamily4/2/2split. Half one initialized source,half two to expose combined heating; true heating/shielding effects must be measured, not assumed from labels. Packing requires each added tree to be within3.5m edge gap of an existing tree or building, creating connected local configurations. These are additional local interactions, not separately fitted model-per-arrangement categories.

12 larger 4–9-tree + building lots: selected geometry-only from the prior catalogue, 0–3 copies/model. Randomly assign six training, three validation and three test layouts from this same pool. Larger training cases fit the SAME shared rules as smaller configurations. This is now same-family generalization, not unseen-size extrapolation. Three held-out tests cannot cover every count/type combination. Model and predictions must be frozen before test outputs are inspected.

Total 108 candidate inputs: 66 training, 21 validation and 21 test. Whole configurations stay in one split; all model variants use the same split. These are proposed inputs, not generated FDS observations. The preview selects two training, one validation and one test example per family, without examining outcomes.

## Why the data need not grow with every lot arrangement
Working hypothesis: a shared tree response function depends on type,internal spatial state and local incident radiation/hot-gas/flow conditions; it does not need to memorize the whole lot. A separate shared interaction/transport rule predicts those conditions from nearby objects and local air state. Repeating those rules composes a scene. Isolated-burn lookup curves are insufficient because neighbours change forcing. Pair examples teach transfer; selected triples expose overlap/shielding/plume effects missing from pair-only transfer. More objects mean more rule evaluations, not automatically more training cases. Savings depend on larger scenes staying within learned local states and interactions. Merged plumes,wakes and nonlocal pressure/flow can violate that hypothesis. It is the experimental question, not an established result.

## Interface to implement before production data
Tree response state must include spatial temperature,fuel/water state; incoming radiation,gas temperature/velocity and a suitable local air state are conditioning variables, not hidden FDS inputs at inference. Tree outputs include heat/fuel emission and state change. Surface state must retain thermal history/depth response, not just instantaneous temperature. Air/transport representation must preserve spatial fields and carry heat/velocity between local regions; an object graph with one scalar/tree cannot reproduce requested gas fields. Candidatepair model and neighbour-aware model share spatial output/normalization. Architecture and parameter count are still to be specified, using training-only development. No train-time teacher-forced building-state shortcut in autonomous validation.

Loss groups: vegetation temperature/fuel histories;building wall/roof temperatures/flux;ground temperatures/flux;gas temperature/HRRPUV. Normalize quantities using training-only scales and weight groups explicitly so abundantcoldcells do not drown activefire errors. Report eachgroup,active-region metrics,heatdose,peaks,timing and full rolloutstability. Optimize trainingloss;selectonvalidation;reportuntouchedtest once. No building-ignition gate and no singlecombinedscore hidingcomponent failures.
