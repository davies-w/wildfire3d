## Goal and comparison
The user's objective is faithful flame/heat evolution across the scene, referenced to FDS, rather than building ignition classification. Primary outputs are time-varying 3D gas temperature and volumetric heat-release rate (HRRPUV), vegetation temperature distributions and fuel release/remaining fuel, and temperatures/incident radiation/convection on ground and building surfaces. Heat-release rate is a flame/reaction-zone proxy, not rendered flame colour. Include air velocity as a diagnostic/input-state candidate because transported heat depends on flow. Ignition of any object is secondary. User selected bare ground first: measure its heating. No combustible ground-cover components in this dataset. Ground must be thermally responsive, not silently adiabatic; generic properties must be fixed identically across all splits before execution.

A whole crown represented by six numbers cannot itself reconstruct these fields. The next model must have a spatial state/output representation or a shared spatial decoder; the old graph is not silently reused with object-level success criteria. Candidate models must predict the same outputs from the same inputs and train/validation/test IDs. No FDS quantities are supplied during autonomous test rollout. Training must include autonomous joint rollout, not measured building boundaries fed into the vegetation model. Architecture and loss definitions are to be fixed before test-output access.

Compare field errors, spatial/temporal locations of hot/reaction zones, and integrated heat-release/fuel histories as well as surface heat dose. Report active-region and whole-domain metrics separately so cold cells do not conceal failures. Separate direct temperature/heat-flux errors from trajectory timing errors; chaotic pointwise disagreement requires ensemble/seed evidence, not an unqualified exact-match claim. Metrics and tolerances must be fixed using training/calibration evidence before opening held-out test labels. Matching FDS does not establish physical accuracy.

## Catalogue
216 building-and-canopy scenes: three building forms (solid rectangular, solid L-shaped, solid courtyard/U-shaped, all flat-roof), one/two/three canopies, 24 draws of each combination. Within each stratum randomly assign16 training,4 validation,4 test. All three forms and every canopy count occur in every split. Continuous building yaw, canopy placement and mutual bearings. Crown-to-building and crown-to-crown clearance at least0.5m; each added canopy is within7m of a building or another canopy. No overlapping crown envelopes. This geometric conditioning applies identically across splits.

72 standalone-canopy cases:24 per shape family, also16/4/4. Each has independently sampled wind, moisture, size and density. Totals192 train,48 validation,48 test. Every model variant uses the same192 training cases, including the additive candidate; any single-only baseline is labelled as an extra restricted-data diagnostic. None of the validation/test scenes are fitted. Time rows, component nodes, replicas and seed repeats of the same geometry must stay together.

This is a stratified random same-distribution design, not strictly unstratified independent sampling. Split assignment is blind to outcomes. Wind speed0.5–8m/s, wind FROM direction0–360 degrees, per-canopy moisture0.06–0.30kg water/kg dry fuel and dry density scale0.7–1.3 sampled independently before geometric acceptance. No synthetic outcomes or promises of balanced ignition labels. All model families receive the same data; test-set label balancing after running is prohibited. If the generator is changed after calibration, generate a new untouched test set under the revised distribution.

## Components and limitations
N: narrow conical crown, radius1.5–2.5m, crown height8–12m, base2–4m. B: broad conical crown, radius3–4m, crown height4–7m, base2–4m. C: columnar cylindrical crown, radius2–3m, crown height9–13m, base2–4m. These are generic shape archetypes, not pine/oak/eucalyptus species calibrations. All use generic vegetation chemistry; geometry, moisture and fuel density vary. No woody trunk yet.

Buildings have8–12m nominal footprint spans,4–7m assigned heights, generic20mm wood thermal surfaces. Solid extrusions omit interiors/windows. No ember model. Initial source is an artificial20s hot-particle source at a selected crown's lower surface, removed by21s; strength and shape coupling require common training-side calibration before execution. It is not a natural ignition process. Inputs propose180s horizon and48x48x24m domain.0.5m is a PROVISIONAL grid, not a convergence claim.
