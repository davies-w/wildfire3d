The stronger caveat is **after the artificial source is removed** (22–180s): CNN32 hot-region MAE43.7°C versus interpolation43.9°C, excess radiation-field dose error59.5% versus17.0%, and total heat-release integral error64.7% versus11.0%. Radiation is integrated intensity, not flux onto an oriented object. The CNN has little temperature advantage in that period and worse heat-release/radiation fidelity. Centered~10s smoothing does not rescue the comparison: full-sequence smoothed hot-region MAE37.9°C versus interpolation31.2°C. This supplementary smoothing is retrospective, not a replacement for raw metrics.
