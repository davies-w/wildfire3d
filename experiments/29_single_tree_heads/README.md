Temperature remains an ambient-relative prediction. A smooth lower bound is derived from the minimum temperature in TRAINING fields, rounded down with2°C margin. This is a constraint for this fixed setup, not a universal physical bound. The scalar strength model learns total heat release from wind, angle and time, with added smooth time-basis features. Combustion spatial weights are normalized to that predicted total; this enforces agreement between the predicted spatial integral and predicted scalar, not accuracy or full energy conservation. No FDS quantities enter CNN inference. Shared trunk remains; output branches can learn distinct residual corrections.
