# Supplemental archive of existing experiment evidence

Preserves 733 existing files (1,423,181,601 bytes) from experiments17–26 that were outside their recorded DVC outputs/imports. No simulation or training is rerun. Original repository-relative paths and individual SHA256 hashes are recorded in manifest.json and retained inside data/supplement.tar.

Runtime locks/PIDs and Python caches are excluded. Existing DVC outputs are pushed separately. The archive stage scans current historical evidence; restoring this snapshot uses `dvc pull`, not regenerating data. Raw solver evidence, model material and local collection records are preserved without treating them as new scientific results.
